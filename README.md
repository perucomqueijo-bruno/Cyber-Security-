##Nosso projeto terá 5 telas responsivas (5 telas para desktop e 5 telas para smartphone), com um prazo para ser entregue até o dia 21/10/2026. Será feito com as linguagens já aprendidas nas outras disciplinas, em HTML e CSS para fazer a estrutura e estilizar respectivamente.

##O que o site terá?
    • Uma tela de menu;
    • Quatro telas restantes, cada uma estando em uma modalidade diferente das apresentadas no menu;
    • A mesma coisa servirá para o sistema de celular.
    • Cada integrante do grupo terá que fazer duas telas, sendo uma de desktop e outra de celular.
